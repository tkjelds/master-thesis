\section*{From the thesis topic document}
LLMs are a useful tool for writing code. However, programs generated by LLMs are not guaranteed to be bug-free. Concurrency bugs are specially difficult to identify, as they require reasoning about multiple execution interleavings. Luckily, there exist tools that can automatically find certian types of concurrency errors. In this project, the goal is to use LLMs to generate thread-safe data structures and evaluate whether they contain concurrency bugs. \cite{huang2026concur}
